Artículo 7.57 Quintus.- Para ser proveedor privado de transporte no se requiere autorizar o registrar vehículos para prestar el servicio, a menos que sea directamente el propietario de la aplicación tecnológica.
No será limitado el número de unidades mínimo o máximo, ni se impondrán requisitos de matrículas especiales, cromáticas o elementos de identificación alguna.
