Artículo 179.- El registro, identificación, localización y control de los inmuebles se hará mediante la asignación de una clave catastral que consiste en un código alfanumérico de dieciséis posiciones: las tres primeras identifican al municipio, las dos siguientes a la zona catastral, tres para la manzana, y dos para el lote; cuando se trate de condominios dos posiciones para identificar el edificio y las cuatro siguientes para el número de departamento o local.
La clave catastral deberá corresponder invariablemente a la estructura señalada.
