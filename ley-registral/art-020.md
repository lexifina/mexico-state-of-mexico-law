Artículo 20.- El Sistema Informático incluirá:
I. Un control de gestión;
II. Un sistema de procedimiento registral;
III. Un sistema de base de datos permanente y actualizado para su consulta pública, incluyendo días y horas inhábiles;
IV. Las bases de datos y archivos complementarios, necesarios para explotar y validar la información; y
V. Los respaldos.
